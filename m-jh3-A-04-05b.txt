## 要件
1. **問題形式**
   - 定期テストや入試を意識した形式
   - **順序**：問題 → 【解答】 → 【解説】
   - **見出し**：問題は「■問題1」のように通常表記、解答・解説は【】を用いる
   - **行末**：`■問題1`/`【解答】`/`【解説】` の行末には**半角スペース2つ**（改行扱い）
2. **解答・解説**
   - ***ステップバイステップ*** で分かりやすく
   - 「間違えやすいポイント」や「コツ」を補足
   - 必要に応じて「別解」や「ポイント整理」を提示
3. **数式ルール**
   - **ディスプレイ数式**：`\[ ... \]`
   - **インライン数式**：`$...$`
   - **筆算の先頭**：列計算の最左に `+)` または `-)`、`×)` などを付ける
   - **分数**：`\frac` を使用（`\tfrac`は使わない）
   - **縦並び**：`=` の位置をそろえる（桁揃えで読みやすく）
   - **乗算記号**： `\times` に統一
4. **出力形式**
   - プレーンテキスト形式（テキストファイルとしてダウンロード可能にする）
   - ファイル名：平方根―平方根の大小―基礎問題.txt

   - 問題は「■問題1」の形式，解答・解説は【】を使用

## 生成例  
■問題1  
次の①〜④の数の大小をくらべ、最も大きい数を選びなさい。
\[
\text{① } \sqrt{6}\quad
\text{② } \frac{\sqrt{12}}{\sqrt{6}}\quad
\text{③ } 3\quad
\text{④ } \frac{3}{2}
\]

【解答】  
\[
\text{③}
\]

【解説】  
**ステップ1：** 平方根の大小の考え方を確認する  

$a,\ b$ が正の数のとき、$a < b$ ならば $\sqrt{a} < \sqrt{b}$ である。
つまり、根号の中の数が大きいほど、平方根も大きくなる。

**ステップ2：** それぞれの数を根号の形にそろえる  

②は、根号のわり算を使って簡単にする。
\[
\frac{\sqrt{12}}{\sqrt{6}}
= \sqrt{\frac{12}{6}}
= \sqrt{2}
\]

③と④も、根号の形で表す。
\[
3 = \sqrt{9},\quad
\frac{3}{2} = \sqrt{\frac{9}{4}}
\]
根号の中の数 $6,\ 2,\ 9,\ \frac{9}{4}$ はすべて正である。

**ステップ3：** 根号の中の数を比べる  

\[
9 > 6 > 2 > \frac{9}{4}
\]

なので、
\[
\sqrt{9} > \sqrt{6} > \sqrt{2} > \sqrt{\frac{9}{4}}
\]
となる。

**ステップ4：** 最も大きい数を選ぶ  

最も大きい数は $3$ である。
したがって、答えは
\[
\text{③}
\]
となる。

■問題2  
次の①〜④の数の大小をくらべ、最も大きい数を選びなさい。
\[
\text{① } \sqrt{0.6}\quad
\text{② } \frac{\sqrt{12}}{\sqrt{6}}\quad
\text{③ } 0.3\quad
\text{④ } \frac{1}{3}
\]

【解答】  
\[
\text{②}
\]

【解説】  
**ステップ1：** 平方根の大小の考え方を確認する  

$a,\ b$ が正の数のとき、$a < b$ ならば $\sqrt{a} < \sqrt{b}$ である。
つまり、根号の中の数を比べれば、平方根の大小が分かる。

**ステップ2：** それぞれの数を根号の形にそろえる  

②は、根号のわり算を使って簡単にする。
\[
\frac{\sqrt{12}}{\sqrt{6}}
= \sqrt{\frac{12}{6}}
= \sqrt{2}
\]

③と④も、根号の形で表す。
\[
0.3 = \sqrt{0.09},\quad
\frac{1}{3} = \sqrt{\frac{1}{9}}
\]
根号の中の数 $0.6,\ 2,\ 0.09,\ \frac{1}{9}$ はすべて正である。

**ステップ3：** 根号の中の数を比べる  

\[
2 > 0.6 > \frac{1}{9} > 0.09
\]

なので、
\[
\sqrt{2} > \sqrt{0.6} > \sqrt{\frac{1}{9}} > \sqrt{0.09}
\]
となる。

**ステップ4：** 最も大きい数を選ぶ  

最も大きい数は $\sqrt{2}$ である。
したがって、答えは
\[
\text{②}
\]
となる。
