## 要件
1. **問題形式**
   - 定期テストや入試を意識した形式
   - **順序**：問題 → 【解答】 → 【解説】
   - **見出し**：問題は「■問題1」のように通常表記、解答・解説は【】を用いる
   - **行末**：`【問題】`/`【解答】`/`【解説】` の行末には**半角スペース2つ**（改行扱い）
2. **解答・解説**
   - ***ステップバイステップ*** で分かりやすく
   - 「間違えやすいポイント」や「コツ」を補足
   - 必要に応じて「別解」や「ポイント整理」を提示
3. **数式ルール**
   - **ディスプレイ数式**：`\[ ... \]`
   - **インライン数式**：`$...$`
   - **筆算の先頭**：列計算の最左に `+)` または `-)`、`×)` などを付ける
   - **分数**：`\frac` を使用（`\tfrac`は使わない）
   - **縦並び**：`=` の位置をそろえる（桁揃えで読みやすく）
   - **乗算記号**： `\times` に統一
4. **出力形式**
   - プレーンテキスト形式（テキストファイルとしてダウンロード可能にする）
   - ファイル名：平方根―有理数と無理数―基礎問題.txt

## 注意点
   - 問題は「■問題1」の形式，解答・解説は【】を使用
   - 難易度は「教科書の基本問題レベル」を基準
   - つまずきやすい箇所には補足解説を加える
   - 文体は常体「〜する」「〜である」「〜となる」にそろえる
   - 選択肢の数式はTeXで表記し、分数は必ず `\frac` を使う

## 生成例  
■問題1  
次の①〜④の各数から、有理数を選択しなさい。
\[
\text{① } \frac{6}{5}\quad
\text{② } \frac{1}{\sqrt{10}}\quad
\text{③ } \sqrt{6}\quad
\text{④ } 1.2
\]

【解答】  
\[
\text{①},\ \text{④}
\]

【解説】  
**ステップ1：** 有理数の意味を確認する  

有理数とは、整数や分数で表せる数のことである。
有限小数や循環小数も有理数である。

**ステップ2：** それぞれの数を確認する  

\[
\frac{6}{5}
\]
は分数なので有理数である。
\[
1.2 = \frac{12}{10} = \frac{6}{5}
\]
なので、$1.2$ も有理数である。

**ステップ3：** 根号をふくむ数を確認する  

\[
\sqrt{6}
\]
は根号をはずせないので無理数である。
また、
\[
\frac{1}{\sqrt{10}}
\]
も、$\sqrt{10}$ が根号をはずせないので無理数である。

**ステップ4：** 答えを書く  

したがって、有理数は
\[
\text{①},\ \text{④}
\]
となる。

■問題2  
次の①〜④の各数から、無理数を選択しなさい。
\[
\text{① } \sqrt{4}\quad
\text{② } \sqrt{3}\quad
\text{③ } \frac{140}{99}\quad
\text{④ } \frac{22}{7}
\]

【解答】  
\[
\text{②}
\]

【解説】  
**ステップ1：** 無理数の意味を確認する  

無理数とは、分数で表せない数のことである。
根号がはずせない数は無理数である。

**ステップ2：** 根号がはずせる数を確認する  

\[
\sqrt{4} = 2
\]
なので、①は有理数である。

**ステップ3：** 根号がはずせない数を確認する  

\[
\sqrt{3}
\]
は根号をはずせないので無理数である。

**ステップ4：** 分数で表されている数を確認する  

\[
\frac{140}{99},\quad \frac{22}{7}
\]
はどちらも分数なので有理数である。

**ステップ5：** 答えを書く  

したがって、無理数は
\[
\text{②}
\]
となる。


以上、生成例
