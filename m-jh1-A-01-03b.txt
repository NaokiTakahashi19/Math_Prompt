1-A-01-03
正と負の数 ― 数の大小と不等号
□基本問題
# 教育コンテンツ制作依頼

## 概要
- **対象**：中学1年生
- **立場**：中学校の数学の教師として
- **単元**：正と負の数 ― 数の大小と不等号
- **内容**：数の大小を不等号記号を使ってあらわすことができる
- **レベル**：基礎レベル（教科書の基本問題レベル）

## 要件
1. **問題形式**
   - 定期テストや入試を意識した形式
   - 問題、解説とも生成例に類似したもの
   - 生成例に準じる
   - **順序**：問題 → 【解答】 → 【解説】
   - **見出し**：問題は「■問題」のように通常表記、解答・解説は【】を用いる
   - **行末**：`■問題`/`【解答】`/`【解説】` の行末には**半角スペース2つ**（改行扱い）
   - 生成例の問題を参考に数字などを入れ替え難易度が類似した問題を生成する
   - 生成例に図やグラフや表がある場合は、それにならう
2. **解答・解説**
   - 【解説】は、生成例の【解説】をひな形として生成する
   - ステップのタイトルは、生成例にしたがう
   - 生成例の解説に図やグラフや表がある場合は、それにならって生成する
3. **数式ルール**
   - **ディスプレイ数式**：`\[ ... \]`
   - **インライン数式**：`$...$`
   - **分数**：`\frac` を使用（`\tfrac`は使わない）
   - **縦並び**：`=` の位置をそろえる（桁揃えで読みやすく）
   - **乗算記号**： `\times` に統一
## 注意点
   - TikZ内の日本語ラベルは避け、点名・長さ・角度は英字・数字・数式で表す
   - 難易度は「教科書の基本問題レベル」を基準
   - つまずきやすい箇所には補足解説を加える
   - 解説では、数直線上で右にある数ほど大きい、正の数は0より大きく負の数は0より小さい、などの判断基準を冒頭で明示する
   - 各ステップでは、「数直線で右にあるから」「0より大きいから」「負の数どうしでは0に近い方が大きいから」など、根拠語を使って説明する
   - 解説の流れは、パターン1：数直線上での位置を考える → $0$ と $-2$ の位置を比べる → 不等号で表す ／ パターン2：数直線上での位置を考える → $-0.1$ と $-0.7$ の位置を比べる → 不等号で表す ／ パターン3：数直線上での位置を考える → 符号の規則を適用する → 不等号で表す

## 生成例  
■問題1  
 次の数の大小を､不等号を使って表しなさい。
\[
0, -2
\]

【解答】  
\[
-2 < 0 　または 　0 > -2
\]

【解説】  
**ステップ1：** 数直線上での位置を考える
数直線では、$0$ より右側に正の数、$0$ より左側に負の数をとる。
また、数直線上では右側にある数ほど大きく、左側にある数ほど小さい。
\begin{tikzpicture}[x=1.35cm,y=1.15cm,>=stealth]
\draw[->,thick] (-3.4,0)--(0.7,0);
\foreach \x/\label in {-3/{-3},-2/{-2},-1/{-1},0/{0}} {
  \draw (\x,0.1)--(\x,-0.1);
  \node[below] at (\x,-0.1) {$\label$};
}
\fill[pink] (-2,0) circle (2.5pt);
\fill[cyan] (0,0) circle (2.5pt);
\end{tikzpicture}

**ステップ2：** $0$ と $-2$ の位置を比べる
$-2$ は $0$ より左側にある。
数直線では左側にある数ほど小さいので、$-2$ は $0$ より小さい。

**ステップ3：** 不等号で表す
小さい数を左側、大きい数を右側に置くと、
\[
\hlpink{-2} < \hlblue{0}
\]
である。
また、大きい数を左側に置いて表すと、
\[
\hlblue{0} > \hlpink{-2}
\]
とも書ける。


■問題2  
 次の数の大小を､不等号を使って表しなさい。
\[
-0.1, -0.7
\]

【解答】  
\[
-0.7 < -0.1 　または　  -0.1 > -0.7
\]

【解説】  
**ステップ1：** 数直線上での位置を考える
数直線では、右側にある数ほど大きく、左側にある数ほど小さい。
負の数どうしを比べるときも、この考え方は同じである。
\begin{tikzpicture}[x=6cm,y=1.15cm,>=stealth]
\draw[->,thick] (-0.9,0)--(0.15,0);
\foreach \x/\label in {-0.8/{-0.8},-0.7/{-0.7},-0.4/{-0.4},-0.1/{-0.1},0/{0}} {
  \draw (\x,0.1)--(\x,-0.1);
  \node[below] at (\x,-0.1) {$\label$};
}
\fill[pink] (-0.7,0) circle (2.5pt);
\fill[cyan] (-0.1,0) circle (2.5pt);
\end{tikzpicture}

**ステップ2：** $-0.1$ と $-0.7$ の位置を比べる
$-0.1$ は $0$ に近く、$-0.7$ より右側にある。
したがって、$-0.1$ の方が大きく、$-0.7$ の方が小さい。

**ステップ3：** 不等号で表す
小さい数を左側、大きい数を右側に置くと、
\[
\hlpink{-0.7} < \hlblue{-0.1}
\]
である。
また、大きい数を左側に置いて表すと、
\[
\hlblue{-0.1} > \hlpink{-0.7}
\]
とも書ける。


■問題3  
 次の数の大小を､不等号を使って表しなさい。
\[
\frac{3}{4}, -\frac{2}{3}
\]

【解答】  
\[
-\frac{2}{3} < \frac{3}{4} 　または　  \frac{3}{4} > -\frac{2}{3}
\]

【解説】  
**ステップ1：** 数直線上での位置を考える
数直線では、$0$ より右側に正の数、$0$ より左側に負の数をとる。
右側にある数ほど大きく、左側にある数ほど小さい。
\begin{tikzpicture}[x=3.2cm,y=1.15cm,>=stealth]
\draw[->,thick] (-1,0)--(1.05,0);
\foreach \x/\label in {-0.666/{-\frac{2}{3}},0/{0},0.75/{\frac{3}{4}}} {
  \draw (\x,0.1)--(\x,-0.1);
  \node[below] at (\x,-0.1) {$\label$};
}
\fill[pink] (-0.666,0) circle (2.5pt);
\fill[cyan] (0.75,0) circle (2.5pt);
\fill[black] (0,0) circle (2.5pt);
\end{tikzpicture}

**ステップ2：** 符号の規則を適用する
$\frac{3}{4}$ は正の数なので、$0$ より右側にある。
$-\frac{2}{3}$ は負の数なので、$0$ より左側にある。
したがって、$\frac{3}{4}$ の方が大きく、$-\frac{2}{3}$ の方が小さい。

**ステップ3：** 不等号で表す
小さい数を左側、大きい数を右側に置くと、
\[
\hlpink{-\frac{2}{3}} < \hlblue{\frac{3}{4}}
\]
である。
また、大きい数を左側に置いて表すと、
\[
\hlblue{\frac{3}{4}} > \hlpink{-\frac{2}{3}}
\]
とも書ける。

以上、生成例
