2-A-02-01
文字式の利用 ― 整数に関するいろいろな性質
□基本問題
# 教育コンテンツ制作依頼

## 概要
- **対象**：中学2年生
- **立場**：中学校の数学の教師として
- **単元**：文字式の利用 ― 整数に関するいろいろな性質
- **内容**：数に関する性質を、文字を使って説明する。
- **レベル**：基礎レベル（教科書の基本問題レベル）

## 要件
1. **問題形式**
   - 定期テストや入試を意識した形式
   - **順序**：問題 → 【解答】 → 【解説】
   - **見出し**：問題は「■問題1」のように通常表記、解答・解説は【】を用いる
   - **行末**：`【問題】`/`【解答】`/`【解説】` の行末には**半角スペース2つ**（改行扱い）
2. **解答・解説**
   - ***ステップバイステップ*** で分かりやすく
   - 「間違えやすいポイント」や「コツ」を補足
   - 必要に応じて「別解」や「ポイント整理」を提示
3. **数式ルール**
   - **ディスプレイ数式**：`\[ ... \]`
   - **インライン数式**：`$...$`
   - **筆算の先頭**：列計算の最左に `+)` または `-)`、`×)` などを付ける
   - **分数**：`\frac` を使用（`\tfrac`は使わない）
   - **縦並び**：`=` の位置をそろえる（桁揃えで読みやすく）
   - **乗算記号**： `\times` に統一
4. **出力形式**
   - プレーンテキスト形式（テキストファイルとしてダウンロード可能にする）
   - ファイル名：文字式の利用―整数に関するいろいろな性質―基礎問題.txt
## 問題レベルの定義
1. 基礎レベル
   - 教科書例題や章の導入問題（計算・定義確認）
   - 正答率：70〜90％
   - 狙い：理解・定着の確認
2. 標準レベル
   - 教科書章末問題，定期テスト中心問題
   - 正答率：40〜70％
   - 狙い：入試基本レベルの土台
3. 発展レベル
   - 入試の良問（条件整理・組み合わせ必要）
   - 正答率：20〜40％
   - 狙い：応用的な筋道立て思考
4. 応用レベル
   - 難関校入試の良問・奇問（発想転換が必要）
   - 正答率：0〜20％
   - 狙い：難関突破・競技数学的力

## 注意点
   - 問題は「■問題1」の形式，解答・解説は【】を使用
   - 難易度は「教科書の基本問題レベル」を基準
   - つまずきやすい箇所には補足解説を加える
   
## 生成例   
■問題1  
奇数と偶数の和は、奇数になりますか？偶数になりますか？  
㋐奇数になる  
㋑偶数になる  
㋒どちらになることもある  

【解答】  
\[
㋐
\]

【解説】  
**ステップ1：** 奇数と偶数を文字式を使って表す  
$m,n$を整数とすると、奇数と偶数は、それぞれ次のように表すことができる。  
奇数：$2m+1$  
偶数：$2ｎ$

**ステップ2：** 奇数と偶数の和を文字式を使って表す  
奇数と偶数の和は、ステップ1より、次のように表すことができる。  
\[
( 2m + 1 )+ 2n
\]

**ステップ3：** 式を整理する  
\[
= 2m + 1 + 2n = 2m + 2n + 1 = 2( m + n ) + 1
\]
**ステップ1：** より、$m,n$はそれぞれ整数なので、$( m + n )$ は整数となる。$2( m + n )$ は整数$( m + n )$ の2倍なので偶数となり、偶数に1を足した数である$2( m + n ) + 1$は、奇数となる。よって、奇数と偶数の和は奇数となる。

■問題2  
連続する3つの整数の和は、かならずある整数の倍数になります。ある整数を次から選びなさい。  
㋐ 2  
㋑ 3  
㋒ 4  
㋓ 5  

【解答】  
\[
㋑
\]

【解説】  
**ステップ1：** 連続する3つの整数を文字式で表す。  
整数を$n$とすると3つの連続する整数は、次のように表すことができる。
\[
n, (n + 1), (n + 2)
\]

**ステップ2：** 連続する3つの整数の和は、次の文字式で表すことができる。  
\[
n + ( n + 1 ) + ( n + 2 )
\]

**ステップ2：** 整理すると  
\[
= n + n + 1 + n + 2 = 3n + 3 = 3 ( n + 1 )
\]
なので、かならず$3$の倍数となる。
