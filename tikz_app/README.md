# TikZ Renderer Web App

このディレクトリには、TikZ 図だけでなく通常のテキストや LaTeX の数式もブラウザ上で描画できる Web アプリケーションが含まれています。左側のテキストエリアに入力した内容を解析し、TikZ 図はサーバー側で SVG に変換、平文はそのまま表示し、数式は MathJax により SVG でレンダリングされます。アプリはローカルで動作し、インターネット接続がなくても使用できます。

このアプリは `Math_Prompt/tikz_app` から起動する前提で、親ディレクトリの `.txt` プロンプトと `Math_Question` ディレクトリを読み書きします。別の場所にある `Math_Prompt` を使う場合は、環境変数 `MATH_PROMPT_DIR` にそのパスを指定してください。

## ファイル構成

- `package.json` – 必要な依存関係 (`express`, `node-tikzjax`) を定義しています。
- `server.js` – Node.js/Express サーバーのメインスクリプト。静的ファイルを提供し、TikZ コードを SVG に変換する API (`POST /render`) を実装しています。
- `public/index.html` – アプリのフロントエンド。TikZ 用の入力エリアと描画結果を表示する領域、およびレンダリングボタンを含んでいます。
- `README.md` – このファイルです。

## 動作方法

1. ターミナルでこのディレクトリに移動します。

2. 依存関係をインストールします。インターネット接続が必要です。

   ```sh
   npm install
   ```

3. サーバーを起動します。

   ```sh
   npm start
   ```

   デフォルトではポート `3000` で起動します。環境変数 `PORT` で変更することもできます。
   別の `Math_Prompt` ディレクトリを参照したい場合は、以下のように指定できます。

   ```sh
   MATH_PROMPT_DIR=/path/to/Math_Prompt npm start
   ```

4. ブラウザで `http://localhost:3000` にアクセスすると、左側に入力欄、右側に描画結果が表示される画面が開きます。入力欄には以下のような内容を混在させることができます。

   - **TikZ 図**: `\begin{tikzpicture} ... \end{tikzpicture}` などを含んでいる場合、サーバーに送信されて SVG に変換されます。

     本アプリではサーバー側で TikZ の `calc` ライブラリを自動的に読み込んでいるため、
     [`node‑tikzjax` の高度な設定](https://www.npmjs.com/package/node-tikzjax#advanced-usage)にある
     `\usetikzlibrary{calc}` を明示的に書かなくても、座標計算
     (`$ (O)!2cm!30:(A) $` など) や `rotate around={...:(...)} ` オプションを用いた回転といった
     高度な描画が利用できます【721566669562627†L98-L111】。特殊文字として度数記号 (°) は
     同梱フォントに含まれていないため `30°` のような表記は `30deg` や `^{\circ}` に置き換えて
     ください。
   - **グラフ描画**: `\begin{graf} ... \end{graf}` で囲んだカスタム環境を使うと、座標範囲を指定して関数のグラフを描画できます。形式は以下の通りです。

     ```
     \begin{graf}
     X=min,max      % x 範囲を指定（省略時は -5〜5）
     Y=min,max      % y 範囲を指定（省略時は -5〜5）
     y = \frac{1}{2}x^2,red   % 描きたい関数と色（カンマの後が色名、指定しなければ青）
     y = 3x + \frac{1}{2},blue
     \end{graf}
     ```

     上記の例では、x 座標を \(-3\)〜4、y 座標を \(-2\)〜5 とした座標平面に、\(\frac{1}{2}x^2\) のグラフを赤色で、\(3x+\frac{1}{2}\) のグラフを青色で描画します。`X=`、`Y=` の行や色指定は任意で、省略した場合はデフォルト値が使われます。

     描画の仕組みには 2 通りの指定方法があります。

     1. **従来通りの範囲指定** – `X=min,max`、`Y=min,max` の行で x 範囲・y 範囲を指定すると、その幅と高さの比率で座標平面が描かれます。x 軸と y 軸の 1 単位あたりの長さは等しく、例えば `X=-5,5`・`Y=-2,5` とすると横方向の長さは 10、縦方向の長さは 7 となり、描かれる平面の縦横比は 7:10 になります。

     2. **座標平面の目盛り数と軸位置を指定する方法** – さらに柔軟に制御したい場合は、`
     H=縦目盛り数
     W=横目盛り数
     Axis=x軸目盛り位置,y軸目盛り位置
     `
     のように指定します。ここで `H` は座標平面の縦方向にいくつ目盛りをとるか、`W` は横方向の目盛り数を表します。`Axis` の第 1 パラメータは **x 軸の位置**（下から何目盛り目か）、第 2 パラメータは **y 軸の位置**（左から何目盛り目か）です。

     例えば、

     ```
     H=10
     W=8
     Axis=3,4
     y = \frac{1}{2}x^2,red
     y = 3x + \frac{1}{2},blue
     ```

     と書くと、縦 10×横 8 の座標平面を用意し、x 軸は下から 3 目盛り目、y 軸は左から 4 目盛り目に描かれます。1 目盛りは 1 数値単位として扱われるため、この例では x 範囲は [-4,4]、y 範囲は [-3,7] となります。グラフの関数指定 (`y = ...`) は従来と同じ形式で記述します。目盛り数の指定がない場合は `X=`・`Y=` の範囲から自動的に比率を計算します。

     `scale=` (または `scales=`) 行を追加すると、方眼用紙のようなグリッド線を描画できます。`scale=1` なら 1 単位ごとに、`scale=2` なら 2 単位ごとに格子線が描かれます。`scale=0` または省略時はグリッドを描きません。

     `scale=` (または `scales=`) 行を追加すると、方眼用紙のようなグリッド線を描画できます。`scale=1` なら 1 単位ごとに、`scale=2` なら 2 単位ごとに格子線が描かれます。`scale=0` または省略時はグリッドを描きません。刻み幅は `X=`・`Y=` で指定した範囲に応じて自動的に調整されます。

     軸には tick マーク（目盛り）が描かれます。指定した範囲に 0 が含まれる場合はその位置に軸が描かれますが、原点が範囲外にある場合は軸線は表示されず、目盛りは平面の端に描かれます。各軸の正の方向の端付近には `x`・`y` のラベルが付けられます。

   - **Markdown 記法**: テキストセグメントでは基本的な Markdown を記述できます。例えば `**太字**` や `*斜体*`、`# 見出し`、`- 箇条書き` などがサポートされています。Markdown はブラウザ側で `marked` により HTML に変換され、`DOMPurify` によってサニタイズされるため、安全にレンダリングされます。MathJax との併用も可能です。オフラインで利用する場合は `marked` と `dompurify` をローカルにコピーし、`index.html` の `<script src="...">` を書き換えてください。

   - **平文**: 日本語や英字など通常のテキストはそのまま右側に表示されます。
   - **LaTeX 数式**: `$...$` や `$$...$$`、`\(...\)`、`\[...\]` の形式で記述した数式はブラウザ側の MathJax により美しい数式としてレンダリングされます。

   入力を変更した後「レンダリング」ボタンをクリックすると、最新の結果が右側に表示されます。

## メモ

- SVG に含まれるフォントを正しく読み込むために、サーバーは `node-tikzjax` 付属のフォントファイルを提供しています。
- 数式のレンダリングには MathJax を使用しており、初期状態では CDN から `tex-svg.js` を読み込んでいます。この部分はインターネット接続が必要です。オフラインで利用したい場合は `npm install mathjax-full` を実行し、`node_modules/mathjax-full/es5/tex-svg.js` と対応する `output/svg/fonts` ディレクトリを `public` 配下にコピーして、`index.html` 内の `<script src="...">` をローカルファイルに書き換えてください。
- `POST /render` エンドポイントでは、送信した TikZ コードをラップするために簡単な LaTeX 文書 (`\begin{document} ... \end{document}`) を生成します。
