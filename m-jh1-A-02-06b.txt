1-A-02-06
文字と式 ― 文字式の加法と減法
□基本問題
# 教育コンテンツ制作依頼

## 概要
- **対象**：中学1年生
- **立場**：中学校の数学の教師として
- **単元**：文字と式 ― 文字式の加法と減法
- **内容**：文字式をまとめることができる
- **レベル**：基礎レベル（教科書の基本問題レベル）

## 要件
1. **問題形式**
   - 定期テストや入試を意識した形式
   - 問題、解説とも生成例に類似したもの
   - 生成例に準じる
   - **順序**：問題 → 【解答】 → 【解説】
   - **見出し**：問題は「■問題」のように通常表記、解答・解説は【】を用いる
   - **行末**：`■問題`/`【解答】`/`【解説】` の行末には**半角スペース2つ**（改行扱い）
   - 生成例の問題を参考に数字などを入れ替え難易度が類似した問題を生成する
   - 生成例に図やグラフや表がある場合は、それにならう
2. **解答・解説**
   - 【解説】は、生成例の【解説】をひな形として生成する
   - ステップのタイトルは、生成例にしたがう
   - 生成例の解説に図やグラフや表がある場合は、それにならって生成する
3. **数式ルール**
   - **ディスプレイ数式**：`\[ ... \]`
   - **インライン数式**：`$...$`
   - **分数**：`\frac` を使用（`\tfrac`は使わない）
   - **縦並び**：`=` の位置をそろえる（桁揃えで読みやすく）
   - **乗算記号**： `\times` に統一
## 注意点
   - 難易度は「教科書の基本問題レベル」を基準
   - つまずきやすい箇所には補足解説を加える
   - 同じ文字の項をまとめるときは、文字式を「係数と文字の積」と見て、係数だけを加減することを説明する
   - 乗法では交換法則・結合法則が成り立つため、数の部分と文字の部分を分けて考え、数の部分を先に計算できることを意識させる
   - 例として、$2a\times3=2\times a\times3=2\times3\times a=6a$ のように、積の順序やまとまりを変えてよいことを示す
   - 同類項をまとめる場面では、同じ文字の項を同じ色でハイライトする
   - 解説では、同類項だけをまとめられる理由を「文字の部分が同じなので係数だけを加減できる」と明示する
   - 各ステップでは、同類項かどうかを判断してから、係数を計算する流れを言葉で説明する
## 生成例  
■問題1  
 次の計算をしなさい。
\[
2x + 5x
\]

【解答】
\[
7x
\]

【解説】  
**ステップ1：** それぞれの項を「係数と文字の積」と見る
\[
\hlblue{2x}+\hlblue{5x}=2\times x+5\times x
\]

**ステップ2：** 同じ文字 $x$ が共通していることを確認する
乗法では交換法則・結合法則が成り立つので、数の部分と文字の部分を分けて考えられます。
\[
= (2 + 5)x
\]

**ステップ3：** 係数を計算する
\[
= 7x
\]
したがって、$2x+5x=7x$ です。

■問題2  
 次の計算をしなさい。
\[
3a - 7a
\]

【解答】
\[
-4a
\]

【解説】  
**ステップ1：** それぞれの項を「係数と文字の積」と見る
\[
\hlblue{3a}-\hlblue{7a}=3\times a-7\times a
\]

**ステップ2：** 同じ文字 $a$ が共通していることを確認する
文字の部分が同じなので、係数だけをひき算します。
\[
= (3 - 7)a
\]

**ステップ3：** 係数を計算する
\[
= -4a
\]
したがって、$3a-7a=-4a$ です。

■問題3  
 次の計算をしなさい。
\[
\frac{1}{3}x - \frac{1}{2}x
\]

【解答】
\[
 -\frac{1}{6}x
\]

【解説】  
**ステップ1：** それぞれの項を「係数と文字の積」と見る
\[
\hlblue{\frac{1}{3}x}-\hlblue{\frac{1}{2}x}
=\frac{1}{3}\times x-\frac{1}{2}\times x
\]

**ステップ2：** 同じ文字 $x$ が共通していることを確認する
乗法では順序やまとまりを変えられるので、共通する $x$ を残して係数をまとめます。
\[
= (\frac{1}{3} - \frac{1}{2})x
\]

**ステップ3：** 係数を計算する
\[
=  (\frac{2}{6} - \frac{3}{6})x = -\frac{1}{6}x
\]
したがって、答えは $-\frac{1}{6}x$ です。

■問題4  
 次の計算をしなさい。
\[
0.7a - 0.5a
\]

【解答】
\[
0.2a
\]

【解説】  
**ステップ1：** それぞれの項を「係数と文字の積」と見る
\[
\hlblue{0.7a}-\hlblue{0.5a}=0.7\times a-0.5\times a
\]

**ステップ2：** 同じ文字 $a$ が共通していることを確認する
文字の部分が同じなので、係数だけを計算します。
\[
= (0.7 - 0.5)a
\]

**ステップ3：** 係数を計算する
\[
= 0.2a
\]
したがって、$0.7a-0.5a=0.2a$ です。

■問題5
 次の計算をしなさい。
\[
7a - 5a - 6a
\]

【解答】
\[
-4a
\]

【解説】  
**ステップ1：** それぞれの項を「係数と文字の積」と見る
\[
\hlblue{7a}-\hlblue{5a}-\hlblue{6a}=7\times a-5\times a-6\times a
\]

**ステップ2：** 同じ文字 $a$ が共通していることを確認する
文字の部分が同じなので、係数 $7,\ -5,\ -6$ をまとめます。
\[
= (7 - 5 - 6)a
\]

**ステップ3：** 係数を計算する
\[
= -4a
\]
したがって、$7a-5a-6a=-4a$ です。

■問題6  
 次の計算をしなさい。
\[
2a-5+6a-3
\]

【解答】
\[
8a - 8
\]

【解説】  
**ステップ1：** 文字の項と数だけの項に分ける
\[
\hlblue{2a}+\bbox[2px,lightyellow]{(-5)}+\hlblue{6a}+\bbox[2px,lightyellow]{(-3)}
=\hlblue{2a}+\hlblue{6a}+\bbox[2px,lightyellow]{(-5)}+\bbox[2px,lightyellow]{(-3)}
\]

**ステップ2：** 同じ文字 $a$ の項をまとめる
$2a$ と $6a$ はどちらも $a$ との積です。乗法では順序やまとまりを変えられるので、係数だけをまとめて考えます。
\[
= (2 + 6)a + (-5 - 3)
\]

**ステップ3：** 係数と数の部分を計算する
\[
= 8a - 8
\]
したがって、$2a-5+6a-3=8a-8$ です。

■問題7  
 次の計算をしなさい。
\[
(2x + 5y + 1) - (-3x + 3y - 2)
\]
【解答】
\[
5x + 2y + 3
\]

【解説】  
**ステップ1：** かっこをはずす
前に $-$ があるかっこは、中の符号をすべて反対にします。
\[
2x + 5y + 1 + 3x - 3y + 2
\]

**ステップ2：** 同じ文字の項どうしが近くなるように並びかえる
たし算では交換法則・結合法則が成り立つので、同じ種類の項を近くに集められます。
\[
= \hlblue{2x} + \hlblue{3x} + \hlpink{5y} - \hlpink{3y} + \bbox[2px,lightyellow]{1} + \bbox[2px,lightyellow]{2}
\]

**ステップ3：** 同じ文字の項をまとめる
$2x$ と $3x$、$5y$ と $-3y$ は、それぞれ同じ文字との積なので、係数だけを計算します。
\[
= \hlblue{(2 + 3)x} + \hlpink{(5 - 3)y} + \bbox[2px,lightyellow]{(1 + 2)}
\]

**ステップ4：** 係数と数の部分を計算する
\[
= 5x + 2y + 3
\]
したがって、答えは $5x+2y+3$ です。
