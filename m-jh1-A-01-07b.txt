1-A-01-07
加法と減法 ― 正と負の数の減法
□基本問題
# 教育コンテンツ制作依頼

## 概要
- **対象**：中学1年生
- **立場**：中学校の数学の教師として
- **単元**：加法と減法 ― 正と負の数の減法
- **内容**：正と負の数のひき算ができる
- **レベル**：基礎レベル（教科書の基本問題レベル）

## 要件
1. **問題形式**
   - 定期テストや入試を意識した形式
   - **順序**：問題 → 【解答】 → 【解説】
   - **見出し**：問題は「■問題1」のように通常表記、解答・解説は【】を用いる
   - **行末**：`【問題】`/`【解答】`/`【解説】` の行末には**半角スペース2つ**（改行扱い）
2. **解答・解説**
   - ***ステップバイステップ*** で分かりやすく
   - 「間違えやすいポイント」や「コツ」を補足
   - 必要に応じて「別解」や「ポイント整理」を提示
3. **数式ルール**
   - **ディスプレイ数式**：`\[ ... \]`
   - **インライン数式**：`$...$`
   - **筆算の先頭**：列計算の最左に `+)` または `-)`、`×)` などを付ける
   - **分数**：`\frac` を使用（`\tfrac`は使わない）
   - **縦並び**：`=` の位置をそろえる（桁揃えで読みやすく）
   - **乗算記号**： `\times` に統一
4. **出力形式**
   - プレーンテキスト形式（テキストファイルとしてダウンロード可能にする）
   - ファイル名：加法と減法―正と負の数の減法―基礎問題.txt
##問題レベルの定義
1. 基礎レベル
   - 教科書例題や章の導入問題（計算・定義確認）
   - 正答率：70〜90％
   - 狙い：理解・定着の確認
2. 標準レベル
   - 教科書章末問題，定期テスト中心問題
   - 正答率：40〜70％
   - 狙い：入試基本レベルの土台
3. 発展レベル
   - 入試の良問（条件整理・組み合わせ必要）
   - 正答率：20〜40％
   - 狙い：応用的な筋道立て思考
4. 応用レベル
   - 難関校入試の良問・奇問（発想転換が必要）
   - 正答率：0〜20％
   - 狙い：難関突破・競技数学的力

## 注意点
   - 問題は「■問題1」の形式，解答・解説は【】を使用
   - 難易度は「教科書の基本問題レベル」を基準
   - つまずきやすい箇所には補足解説を加える
## 生成例  
■問題1  
 次の計算をしなさい。
\[
(-9) - (-2)
\]

【解答】  
\[
-7
\]

【解説】  
ステップ1：引き算をたし算に直すルールを思い出そう

\[
a - b = a + (-b)
\]

今回の式は

\[
(-9) - (-2) = (-9) + \bigl(-(-2)\bigr)
\]

ステップ2：符号を整理しよう
$-(-2)$ は「マイナスのマイナス」でプラスになる。

\[
(-9) + (+2)
\]

ステップ3：符号が違う数のたし算のルール
→ 絶対値を比べ，大きい方の符号を結果につける。

\[
|{-9}| = 9,\quad |2| = 2\quad\Rightarrow\quad 9>2
\]

→ 結果は「−」，差は

\[
9 - 2 = 7
\]

ステップ4：答えを書く

\[
-7
\]

■問題2  
 次の計算をしなさい。
\[
(+7) - (-6)
\]

【解答】  
\[
13
\]

【解説】  
ステップ1：引き算をたし算に直す

\[
(+7) - (-6) = (+7) + \bigl(-(-6)\bigr)
\]

ステップ2：符号を整理

\[
-(-6) = +6
\]

よって

\[
(+7) + (+6)
\]

ステップ3：符号が同じ数のたし算のルール
→ 絶対値をたして，その符号をつける。

\[
7 + 6 = 13
\]

符号は「＋」だが，答えは「$13$」と書く。

ステップ4：答えを書く

\[
13
\]

■問題3  
 次の計算をしなさい。
\[
(-4) - (-11)
\]

【解答】  
\[
7
\]

【解説】  
ステップ1：引き算をたし算に直す

\[
(-4) - (-11) = (-4) + \bigl(-(-11)\bigr)
\]

ステップ2：符号を整理

\[
-(-11) = +11
\]

よって

\[
(-4) + (+11)
\]

ステップ3：符号が違う数のたし算のルール
→ 絶対値を比べ，大きい方の符号を結果につける。

\[
|{-4}| = 4,\quad |11| = 11\quad\Rightarrow\quad 11>4
\]

差は

\[
11 - 4 = 7
\]

符号は「＋」

ステップ4：答えを書く

\[
7
\]

■問題4  
 次の計算をしなさい。
\[
0 - (-3)$
\]

【解答】  
\[
3
\]

【解説】  
ステップ1：引き算をたし算に直す

\[
0 - (-3) = 0 + \bigl(-(-3)\bigr)
\]

ステップ2：符号を整理

\[
-(-3) = +3
\]

よって

\[
0 + 3
\]

ステップ3：0に数をたすとその数になる

\[
0 + 3 = 3
\]

ステップ4：答えを書く

\[
3
\]
