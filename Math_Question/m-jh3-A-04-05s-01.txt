■問題
次の①〜④の数の大小をくらべ、最も大きい数を選びなさい。
\[
\text{① } 2\sqrt{3}\quad
\text{② } \sqrt{15}\quad
\text{③ } \frac{7}{2}\quad
\text{④ } \frac{\sqrt{50}}{2}
\]

【解答】  
\[
\text{②}
\]

【解説】  
**ステップ1：平方根の大小の考え方を確認する**

①〜④はすべて正の数である。正の数どうしを比べるときは、根号の形にそろえると大小を比べやすい。

$a,\ b$ が正の数のとき、$a < b$ ならば $\sqrt{a} < \sqrt{b}$ である。

**ステップ2：それぞれの数を根号の形にそろえる**

①は、根号の外にある $2$ を根号の中に入れる。
\[
2\sqrt{3}
= \sqrt{4}\times \sqrt{3}
= \sqrt{4\times 3}
= \sqrt{12}
\]

②はそのままである。
\[
\sqrt{15}
\]

③は正の数なので、根号の形に直す。
\[
\frac{7}{2}
= \sqrt{\left(\frac{7}{2}\right)^2}
= \sqrt{\frac{49}{4}}
\]

④は分母の $2$ を $\sqrt{4}$ と考える。
\[
\frac{\sqrt{50}}{2}
= \frac{\sqrt{50}}{\sqrt{4}}
= \sqrt{\frac{50}{4}}
= \sqrt{\frac{25}{2}}
\]

**ステップ3：根号の中の数を比べる**

根号の中の数を分母が $4$ の形にそろえる。
\[
12=\frac{48}{4},\quad
\frac{49}{4}=\frac{49}{4},\quad
\frac{25}{2}=\frac{50}{4},\quad
15=\frac{60}{4}
\]

したがって、
\[
\frac{48}{4}<\frac{49}{4}<\frac{50}{4}<\frac{60}{4}
\]
より、
\[
12<\frac{49}{4}<\frac{25}{2}<15
\]
となる。

よって、
\[
\sqrt{12}<\sqrt{\frac{49}{4}}<\sqrt{\frac{25}{2}}<\sqrt{15}
\]
である。

**ステップ4：答えを確認する**

最も大きい数は $\sqrt{15}$ である。

したがって、答えは
\[
\text{②}
\]
となる。

**間違えやすいポイント：** 根号の外の数を中に入れるときは、その数を2乗して入れる。たとえば、$2\sqrt{3}=\sqrt{12}$ であり、$\sqrt{6}$ ではない。
