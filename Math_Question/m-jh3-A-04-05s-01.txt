■問題  
次の4つの数を小さい順に並べなさい。
\[
\frac{\sqrt{50}}{6},\quad \sqrt{\frac{5}{3}},\quad \frac{4}{3},\quad 1.2
\]

【解答】  
\[
\frac{\sqrt{50}}{6} < 1.2 < \sqrt{\frac{5}{3}} < \frac{4}{3}
\]

【解説】  
**ステップ1：考え方を確認する**

平方根をふくむ数の大小を比べるときは、すべてを $\sqrt{\ }$ の形にそろえると比べやすい。

$a,\ b$ が正の数のとき、
\[
a < b \quad \text{ならば} \quad \sqrt{a} < \sqrt{b}
\]
である。

つまり、すべて正の数を根号の形にそろえれば、根号の中の数を比べればよい。

**ステップ2：それぞれの数を根号の形にそろえる**

まず、$\frac{\sqrt{50}}{6}$ を根号の形にする。
\[
\frac{\sqrt{50}}{6}
= \frac{\sqrt{50}}{\sqrt{36}}
= \sqrt{\frac{50}{36}}
= \sqrt{\frac{25}{18}}
\]

次に、$\frac{4}{3}$ と $1.2$ を根号の形にする。
\[
\frac{4}{3}
= \sqrt{\left(\frac{4}{3}\right)^2}
= \sqrt{\frac{16}{9}}
\]
\[
1.2
= \frac{6}{5}
= \sqrt{\left(\frac{6}{5}\right)^2}
= \sqrt{\frac{36}{25}}
\]

したがって、4つの数は次のように表せる。
\[
\frac{\sqrt{50}}{6}=\sqrt{\frac{25}{18}},\quad
\sqrt{\frac{5}{3}},\quad
\frac{4}{3}=\sqrt{\frac{16}{9}},\quad
1.2=\sqrt{\frac{36}{25}}
\]

**ステップ3：根号の中の数を比べる**

根号の中の数を比べる。
\[
\frac{25}{18},\quad \frac{5}{3},\quad \frac{16}{9},\quad \frac{36}{25}
\]

小さい順を確認すると、
\[
\frac{25}{18} < \frac{36}{25} < \frac{5}{3} < \frac{16}{9}
\]
である。

よって、
\[
\sqrt{\frac{25}{18}} < \sqrt{\frac{36}{25}} < \sqrt{\frac{5}{3}} < \sqrt{\frac{16}{9}}
\]
となる。

**ステップ4：もとの数にもどして答えを確認する**

それぞれもとの数にもどすと、
\[
\sqrt{\frac{25}{18}}=\frac{\sqrt{50}}{6},\quad
\sqrt{\frac{36}{25}}=1.2,\quad
\sqrt{\frac{16}{9}}=\frac{4}{3}
\]
である。

したがって、小さい順は
\[
\frac{\sqrt{50}}{6} < 1.2 < \sqrt{\frac{5}{3}} < \frac{4}{3}
\]
となる。

**間違えやすいポイント**

$\sqrt{50}$ だけを約 $7$ として考え、$\frac{\sqrt{50}}{6}$ を正しく比べられないことがある。根号をふくむ分数は、
\[
\frac{\sqrt{50}}{6}
= \sqrt{\frac{25}{18}}
\]
のように、分母も根号の中に入れてから比べるのがコツである。
