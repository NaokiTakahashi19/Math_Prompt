■問題
次の式の同類項をまとめなさい。
\[
\frac{2}{3}x^2 - 5xy + \frac{1}{6}x^2 + 2xy
\]

【解答】  
\[
\frac{5}{6}x^2 - 3xy
\]

【解説】  
文字の部分が同じ項を同類項という。  
同類項は、文字の部分はそのままにして、係数だけを計算してまとめる。  
同類項は、共通因数でくくって1つの項にまとめることができる。
\[
ax+bx=(a+b)x
\]

**ステップ1：同類項どうしを確認する**
\[
\hlblue{\frac{2}{3}x^2}-\hlpink{5xy}+\hlblue{\frac{1}{6}x^2}+\hlpink{2xy}
\]

**ステップ2：項を同類項ごとに並びかえる**
\[
\begin{aligned}
&\frac{2}{3}x^2 - 5xy + \frac{1}{6}x^2 + 2xy\\
&= \hlblue{\frac{2}{3}x^2}+\hlblue{\frac{1}{6}x^2}-\hlpink{5xy}+\hlpink{2xy}
\end{aligned}
\]

**ステップ3：同類項を共通因数でくくってまとめる**
\[
= \left(\frac{2}{3}+\frac{1}{6}\right)x^2+(-5+2)xy
\]

**ステップ4：係数を計算する**
\[
\begin{aligned}
&= \left(\frac{4}{6}+\frac{1}{6}\right)x^2+(-3)xy\\
&= \frac{5}{6}x^2-3xy
\end{aligned}
\]

**ステップ5：答えを確認する**
\[
x^2 \text{の項は } \frac{2}{3}x^2 \text{ と } \frac{1}{6}x^2,\quad
xy \text{の項は } -5xy \text{ と } 2xy
\]
となり、文字の部分が同じ項だけをまとめている。  
$x^2$ と $xy$ は文字の部分が違うので、まとめることはできない。分数の係数は通分して計算するのがコツである。

**確認ポイント**
同類項をまとめるときは、文字の部分が同じ項だけを係数で計算します。
