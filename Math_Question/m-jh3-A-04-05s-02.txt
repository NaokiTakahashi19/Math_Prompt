■問題
次の①〜④の数を、小さい順に並べなさい。
\[
\text{① } \frac{\sqrt{50}}{5}\quad
\text{② } \sqrt{\frac{3}{2}}\quad
\text{③ } \frac{5}{3}\quad
\text{④ } \frac{2\sqrt{6}}{3}
\]

【解答】  
\[
\text{②，①，④，③}
\]

【解説】  
**ステップ1：平方根の大小の考え方を確認する**

$a,\ b$ が正の数のとき、$a < b$ ならば $\sqrt{a} < \sqrt{b}$ である。

したがって、すべての数を $\sqrt{\ }$ の形にそろえると、根号の中の数を比べるだけで大小を判断できる。

**ステップ2：それぞれの数を根号の形にそろえる**

①は分母もふくめて根号の中に入れる。
\[
\frac{\sqrt{50}}{5}
= \frac{\sqrt{50}}{\sqrt{25}}
= \sqrt{\frac{50}{25}}
= \sqrt{2}
\]

②はすでに根号の形である。
\[
\sqrt{\frac{3}{2}}
\]

③も根号の形に直す。
\[
\frac{5}{3}
= \sqrt{\left(\frac{5}{3}\right)^2}
= \sqrt{\frac{25}{9}}
\]

④は係数と分母をまとめて根号の中に入れる。
\[
\frac{2\sqrt{6}}{3}
= \sqrt{\left(\frac{2\sqrt{6}}{3}\right)^2}
= \sqrt{\frac{4 \times 6}{9}}
= \sqrt{\frac{24}{9}}
= \sqrt{\frac{8}{3}}
\]

**ステップ3：根号の中の数を比べる**

比べる数は次の4つである。
\[
\frac{3}{2},\quad 2,\quad \frac{25}{9},\quad \frac{8}{3}
\]

小さい順に並べると、
\[
\frac{3}{2} < 2 < \frac{8}{3} < \frac{25}{9}
\]

よって、
\[
\sqrt{\frac{3}{2}} < \sqrt{2} < \sqrt{\frac{8}{3}} < \sqrt{\frac{25}{9}}
\]
となる。

**ステップ4：もとの番号に戻して答えを確認する**

それぞれ対応させると、
\[
\sqrt{\frac{3}{2}}=\text{②},\quad
\sqrt{2}=\text{①},\quad
\sqrt{\frac{8}{3}}=\text{④},\quad
\sqrt{\frac{25}{9}}=\text{③}
\]

したがって、小さい順は
\[
\text{②，①，④，③}
\]
となる。

**間違えやすいポイント：** $\frac{2\sqrt{6}}{3}$ を根号の形にするとき、$2$ だけでなく分母の $3$ も平方する必要がある。つまり、
\[
\left(\frac{2\sqrt{6}}{3}\right)^2
= \frac{4 \times 6}{9}
\]
となる。係数だけを見て大小を決めないようにする。
