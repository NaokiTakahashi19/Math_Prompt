※平方根 ― 平方根の大小
□標準問題
# 教育コンテンツ制作依頼

## 概要
- **対象**：中学3年生
- **立場**：中学生向けの塾講師として
- **単元**：平方根 ― 平方根の大小
- **内容**：平方根をふくむ数の大小比較
- **レベル**：標準レベル（定期テスト中心レベル）

## 要件
1. **問題形式**
   - 定期テストや入試を意識した形式
   - 問題、解説とも生成例に類似したもの
   - 生成例に準じる
   - **順序**：問題 → 【解答】 → 【解説】
   - **見出し**：問題は「■問題」のように通常表記、解答・解説は【】を用いる
   - **行末**：`■問題`/`【解答】`/`【解説】` の行末には**半角スペース2つ**（改行扱い）
   - 生成例の問題を参考に数字などを入れ替え難易度が類似した問題を生成する
   - 生成例に図やグラフや表がある場合は、それにならう
2. **解答・解説**
   - 【解説】は、生成例の【解説】をひな形として生成する
   - ステップのタイトルは、生成例にしたがう
   - 生成例の解説に図やグラフや表がある場合は、それにならって生成する
3. **数式ルール**
   - **ディスプレイ数式**：`\[ ... \]`
   - **インライン数式**：`$...$`
   - **分数**：`\frac` を使用（`\tfrac`は使わない）
   - **縦並び**：`=` の位置をそろえる（桁揃えで読みやすく）
   - **乗算記号**： `\times` に統一
## 注意点
   - 難易度は「標準レベル（定期テスト中心レベル）」を基準
   - つまずきやすい箇所には補足解説を加える
   - 選択肢の数式はTeXで表記し、分数は必ず `\frac` を使う
   - $a,\ b$ が正の数のとき、$a < b$ ならば $\sqrt{a} < \sqrt{b}$ であることを使って大小を比べる
   
## 生成例  
■問題1  
次の①〜④の数の大小をくらべ、最も大きい数を選びなさい。
\[
\text{① } \sqrt{6}\quad
\text{② } \frac{\sqrt{12}}{\sqrt{6}}\quad
\text{③ } 3\quad
\text{④ } \frac{3}{2}
\]

【解答】  
\[
\text{③}
\]

【解説】  
**ステップ1：** 平方根の大小の考え方を確認する

$a,\ b$ が正の数のとき、$a < b$ ならば $\sqrt{a} < \sqrt{b}$ です。
つまり、根号の中の数が大きいほど、平方根も大きくなります。

**ステップ2：** それぞれの数を根号の形にそろえる

②は、根号のわり算を使って簡単にします。
\[
\frac{\sqrt{12}}{\sqrt{6}}
= \sqrt{\frac{12}{6}}
= \sqrt{2}
\]

③と④も、根号の形で表します。
\[
3 = \sqrt{9},\quad
\frac{3}{2} = \sqrt{\frac{9}{4}}
\]
根号の中の数 $6,\ 2,\ 9,\ \frac{9}{4}$ はすべて正です。

**ステップ3：** 根号の中の数を小さい順に並べる

\[
2 < \frac{9}{4} < 6 < 9
\]

なので、
\[
\sqrt{2} < \sqrt{\frac{9}{4}} < \sqrt{6} < \sqrt{9}
\]
となります。

**ステップ4：** 最も大きい数を選ぶ

最も大きい数は $3$ です。
したがって、答えは
\[
\text{③}
\]
となります。

■問題2  
次の①〜④の数の大小をくらべ、最も大きい数を選びなさい。
\[
\text{① } \sqrt{0.6}\quad
\text{② } \frac{\sqrt{12}}{\sqrt{6}}\quad
\text{③ } 0.3\quad
\text{④ } \frac{1}{3}
\]

【解答】  
\[
\text{②}
\]

【解説】  
**ステップ1：** 平方根の大小の考え方を確認する

$a,\ b$ が正の数のとき、$a < b$ ならば $\sqrt{a} < \sqrt{b}$ です。
つまり、根号の中の数を比べれば、平方根の大小が分かります。

**ステップ2：** それぞれの数を根号の形にそろえる

②は、根号のわり算を使って簡単にします。
\[
\frac{\sqrt{12}}{\sqrt{6}}
= \sqrt{\frac{12}{6}}
= \sqrt{2}
\]

③と④も、根号の形で表します。
\[
0.3 = \sqrt{0.09},\quad
\frac{1}{3} = \sqrt{\frac{1}{9}}
\]
根号の中の数 $0.6,\ 2,\ 0.09,\ \frac{1}{9}$ はすべて正です。

**ステップ3：** 根号の中の数を小さい順に並べる

\[
0.09 < \frac{1}{9} < 0.6 < 2
\]

なので、
\[
\sqrt{0.09} < \sqrt{\frac{1}{9}} < \sqrt{0.6} < \sqrt{2}
\]
となります。

**ステップ4：** 最も大きい数を選ぶ

最も大きい数は $\sqrt{2}$ です。
したがって、答えは
\[
\text{②}
\]
となります。

以上、生成例
