1-A-02-06
文字と式 ― 文字式の加法と減法
□標準問題
# 教育コンテンツ制作依頼

## 概要
- **対象**：中学1年生
- **立場**：中学生向けの塾講師として
- **単元**：文字と式 ― 文字式の加法と減法
- **内容**：文字式をまとめることができる
- **レベル**：標準レベル（定期テスト中心レベル）

## 要件
1. **問題形式**
   - 定期テストや入試を意識した形式
   - 問題、解説とも生成例に類似したもの
   - 生成例に準じる
   - **順序**：問題 → 【解答】 → 【解説】
   - **見出し**：問題は「■問題」のように通常表記、解答・解説は【】を用いる
   - **行末**：`■問題`/`【解答】`/`【解説】` の行末には**半角スペース2つ**（改行扱い）
   - 生成例の問題を参考に数字などを入れ替え難易度が類似した問題を生成する
   - 生成例に図やグラフや表がある場合は、それにならう
2. **解答・解説**
   - 【解説】は、生成例の【解説】をひな形として生成する
   - ステップのタイトルは、生成例にしたがう
   - 生成例の解説に図やグラフや表がある場合は、それにならって生成する
3. **数式ルール**
   - **ディスプレイ数式**：`\[ ... \]`
   - **インライン数式**：`$...$`
   - **分数**：`\frac` を使用（`\tfrac`は使わない）
   - **縦並び**：`=` の位置をそろえる（桁揃えで読みやすく）
   - **乗算記号**： `\times` に統一
## 注意点
   - 難易度は「標準レベル（定期テスト中心レベル）」を基準
   - つまずきやすい箇所には補足解説を加える
   - 同類項をまとめるときは、文字式を「係数と文字の積」と見て、係数だけを加減することを説明する
   - 同類項をまとめる場面では、同類項を同じ色でハイライトする
   - かっこの前にマイナスがある場合は、かっこの中の符号をすべて反対にすることを説明する
   - 解説の流れは、パターン1：文字の項と数だけの項に分ける → 同類項を見つける → 同類項をまとめる → 式を簡単にする ／ パターン2：括弧を外す → 同類項を見つける → 同類項をまとめる → 式を簡単にする

## 生成例  
■問題1  
次の計算をしなさい。
\[
3x - 4y + 5 - 2x + 7y - 8
\]

【解答】
\[
x + 3y - 3
\]

【解説】  
**ステップ1：** 文字の項と数だけの項に分ける
\[
\hlblue{3x}-\hlpink{4y}+\bbox[2px,lightyellow]{5}-\hlblue{2x}+\hlpink{7y}-\bbox[2px,lightyellow]{8}
\]

**ステップ2：** 同類項を見つける
\[
= \hlblue{3x}-\hlblue{2x}-\hlpink{4y}+\hlpink{7y}+\bbox[2px,lightyellow]{5}-\bbox[2px,lightyellow]{8}
\]

**ステップ3：** 同類項をまとめる
\[
=(3-2)x+(-4+7)y+(5-8)
\]

**ステップ4：** 式を簡単にする
\[
=x+3y-3
\]

■問題2  
次の計算をしなさい。
\[
(4a - 3b + 2) - (a + 5b - 6)
\]

【解答】
\[
3a - 8b + 8
\]

【解説】  
**ステップ1：** 括弧を外す
前に $-$ があるかっこは、中の符号をすべて反対にします。
\[
-(a+5b-6)=-a-5b+6
\]
したがって、
\[
4a - 3b + 2 - a - 5b + 6
\]

**ステップ2：** 同類項を見つける
\[
= \hlblue{4a}-\hlblue{a}-\hlpink{3b}-\hlpink{5b}+\bbox[2px,lightyellow]{2}+\bbox[2px,lightyellow]{6}
\]

**ステップ3：** 同類項をまとめる
\[
=(4-1)a+(-3-5)b+(2+6)
\]

**ステップ4：** 式を簡単にする
\[
=3a-8b+8
\]

■問題3  
次の計算をしなさい。
\[
(2x + 5y + 1) - (-3x + 3y - 2)
\]

【解答】
\[
5x + 2y + 3
\]

【解説】  
**ステップ1：** 括弧を外す
前に $-$ があるかっこは、中の符号をすべて反対にします。
\[
2x + 5y + 1 + 3x - 3y + 2
\]

**ステップ2：** 同類項を見つける
たし算では交換法則・結合法則が成り立つので、同類項を近くに集められます。
\[
= \hlblue{2x} + \hlblue{3x} + \hlpink{5y} - \hlpink{3y} + \bbox[2px,lightyellow]{1} + \bbox[2px,lightyellow]{2}
\]

**ステップ3：** 同類項をまとめる
$2x$ と $3x$、$5y$ と $-3y$ は、それぞれ同じ文字との積なので、係数だけを計算します。
\[
= \hlblue{(2 + 3)x} + \hlpink{(5 - 3)y} + \bbox[2px,lightyellow]{(1 + 2)}
\]

**ステップ4：** 式を簡単にする
\[
= 5x + 2y + 3
\]

以上、生成例
