# 教育コンテンツ制作依頼

## 概要
- **対象**：中学1年生
- **立場**：中学校の数学の教師として
- **単元**：１次方程式 ― 方程式とその解（代入）②
- **内容**：方程式にいろいろな値を代入して解を求める
- **レベル**：基礎レベル（教科書の基本問題レベル）

## 要件
1. **問題形式**
   - 定期テストや入試を意識した形式
   - **順序**：問題 → 【解答】 → 【解説】
   - **見出し**：問題は「■問題1」のように通常表記、解答・解説は【】を用いる
   - **行末**：`■問題1`/`【解答】`/`【解説】` の行末には**半角スペース2つ**（改行扱い）
2. **解答・解説**
   - ***ステップバイステップ*** で分かりやすく
   - 「間違えやすいポイント」や「コツ」を補足
   - 必要に応じて「別解」や「ポイント整理」を提示
3. **数式ルール**
   - **ディスプレイ数式**：`\[ ... \]`
   - **インライン数式**：`$...$`
   - **筆算の先頭**：列計算の最左に `+)` または `-)`、`×)` などを付ける
   - **分数**：`\frac` を使用（`\tfrac`は使わない）
   - **縦並び**：`=` の位置をそろえる（桁揃えで読みやすく）
   - **乗算記号**： `\times` に統一
4. **出力形式**
   - プレーンテキスト形式（テキストファイルとしてダウンロード可能にする）
   - ファイル名：１次方程式―方程式とその解（代入）②―基礎問題.txt
## 問題レベルの定義
1. 基礎レベル
   - 教科書例題や章の導入問題（計算・定義確認）
   - 正答率：70〜90％
   - 狙い：理解・定着の確認
2. 標準レベル
   - 教科書章末問題，定期テスト中心問題
   - 正答率：40〜70％
   - 狙い：入試基本レベルの土台
3. 発展レベル
   - 入試の良問（条件整理・組み合わせ必要）
   - 正答率：20〜40％
   - 狙い：応用的な筋道立て思考
4. 応用レベル
   - 難関校入試の良問・奇問（発想転換が必要）
   - 正答率：0〜20％
   - 狙い：難関突破・競技数学的力

## 注意点
   - 問題は「■問題1」の形式，解答・解説は【】を使用
   - 難易度は「教科書の基本問題レベル」を基準
   - つまずきやすい箇所には補足解説を加える
   
## 生成例  
■問題1  
次の方程式で、$0$ が解となるものを選びなさい。
① $2x - 8 = 2$
② $\displaystyle \frac{2}{3} = 3x$
③ $\displaystyle \frac{3}{2}x = 2$
④ $2(1 - x) = x + 2$

【解答】
④

【解説】  
**ステップ1：** それぞれの方程式に $x = 0$ を代入して左辺と右辺が等しいかを調べましょう。

① 左辺：$2 \times 0 - 8 = -8$，右辺：$2$ → 等しくない
② 左辺：$\displaystyle \frac{2}{3}$，右辺：$3 \times 0 = 0$ → 等しくない
③ 左辺：$\displaystyle \frac{3}{2} \times 0 = 0$，右辺：$2$ → 等しくない
④ 左辺：$2(1 - 0) = 2$，右辺：$0 + 2 = 2$ → 等しい！

したがって、$x = 0$ が解になるのは ④番です。


■問題２
次の方程式で、$3$ が解となるものを選びなさい。
① $x + 5 = 2$
② $6 + 5x = 3$
③ $\displaystyle \frac{2}{3}x = 2$
④ $2x + 3 = 4x + 2$

【解答】
③

【解説】  
**ステップ1：** $x = 3$ をそれぞれの方程式に代入して確認しましょう。

① 左辺：$3 + 5 = 8$，右辺：$2$ → 等しくない
② 左辺：$6 + 5 \times 3 = 6 + 15 = 21$，右辺：$3$ → 等しくない
③ 左辺：$\displaystyle \frac{2}{3} \times 3 = 2$，右辺：$2$ → 等しい！
④ 左辺：$2 \times 3 + 3 = 6 + 3 = 9$，右辺：$4 \times 3 + 2 = 12 + 2 = 14$ → 等しくない

※③が正解のように見えますが、問題に「等しいものを**選びなさい**」とあるため複数選択肢の可能性をチェックします。

したがって、$x = 3$ が解になるのは ③番 です。
